# JavaScript Todo List App

This is my final project for JavaScript course

## Features
- Add todo
- Mark todo as completed
- Delete todo
- Filter (All / Active / Completed)
- Save data using localStorage

## Concepts Used
- Variables (let, const)
- Functions
- Arrays & Objects
- map / filter
- DOM manipulation
- localStorage

## What I Learned
I learned how to work with DOM, events, arrays and localStorage.
